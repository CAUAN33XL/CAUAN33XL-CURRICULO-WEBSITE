# CAUAN33XL CURRICULO WEBSITE

Website currículo e portfólio profissional para a marca/selo **33XL**.

## 🚀 Tecnologias

Este projeto foi construído utilizando as seguintes tecnologias:

- React
- TypeScript
- Vite
- Tailwind CSS / Vanilla CSS
- E algumas automações em Python / Node.js para formatação de dados.

## 📦 Como executar o projeto

1. **Clone o repositório ou acesse o diretório do projeto:**
   ```bash
   cd CAUAN33XL-CURRICULO-WEBSITE
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Para criar a versão de produção (Build):**
   ```bash
   npm run build
   ```

## 🛠️ Scripts e Ferramentas Auxiliares

O projeto conta com alguns scripts locais para ajudar na manutenção dos dados do currículo:
- `update_dark.py`
- `update_docx.py`
- `update_resume_labels.py`
- `rewrite_docx.js`
- `test-qr.ts`

*(As instruções de uso desses scripts dependem da configuração local).*

## 📄 Estrutura de Pastas

- `/src` - Contém todo o código-fonte do front-end (componentes, páginas, assets).
- `/public` - Arquivos estáticos servidos diretamente.
- `/experiences` - (A ser definido / arquivos ou dados soltos).
- `/output` - (Diretório para arquivos gerados por scripts auxiliares).
